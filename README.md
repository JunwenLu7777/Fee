# hud

Claude Code 的 mod：在输入框下方显示自定义 HUD——模型、上下文、花费、限额、分支、本轮计时等。`/hud` 可切换开关。

另外每轮回复的最后一段下面有个暗色的 `copy`，鼠标指到它时前面出现 `❯`，点一下把这段放进剪贴板（全屏模式下才能点）。

- **额度预测**：照这个额度窗口开始到现在的平均速度，重置前就会用完时，额度后面写「约 15:40 用完」并变黄，离用完不到窗口的十分之一（5 小时额度是半小时）变红；每个窗口弹一次提示。窗口刚开始（前十分之一）或用得不到 5% 时不预测。
- **上下文还能撑几轮**：照最近 5 轮上下文平均每轮涨多少，离自动压缩不到 10 轮时，`ctx` 后面写「约 N 轮后压缩」，3 轮以内变黄、1 轮以内变红。自动压缩的点由 Claude Code 在本地估出来，不发请求；跑满两轮才开始估，自动压缩关着时不写。
- **原地打转提醒**：主对话一轮里同一条命令连着失败 3 次、同一个文件改到 10 次，各弹一次提示。
- **在 `/config` 里能改的**：打转提醒的两个次数（0 不提醒）、额度会提前用完时弹不弹提示、额度窗口过了百分之几才预测（默认 10）、离自动压缩几轮以内才写（默认 10，0 不写）。改完插件自动重新加载。
- **每轮小票**：每轮结尾那行（`✻ … for 1m 14s`）下面写这一轮花了多少、改了哪些文件、跑了几条命令、几条失败、起了几个子 agent。在 git 仓库里，改的文件和行数是这一轮开始、结束各拍一张 git 快照比出来的：Bash、脚本改的也算，同一处改几次只算最后的结果；你在这一轮里自己改的也会算进去。HUD 上的 `+N -M` 同理，是会话开始以来净改的。快照用临时暂存区，不动你自己的暂存区；不是 git 仓库、或者仓库大到拍一次超过 5 秒时，退回按 Edit / Write 的改动累加。模型那边的缓存没接上的轮次，小票上写「缓存过期，重算 85k」（换了模型的写「换了模型，缓存重算 85k」）：模型闲了 5 分钟以上（你很久没发消息，或者中间一条命令跑了很久）再请求，缓存多半过期了，整段上下文要重新算一遍，又慢又多耗额度。只在说得出原因时写；上下文变小了（压缩过）、别的原因没接上的不写。
- **改动侧边栏**：git 仓库里启动时在右边打开一栏（终端 144 列以上才自己摆出来），列出这个会话改过的文件和各自 `+N -M`，`●` 是这一轮改过的；点一个文件看它从会话开始到现在改了哪几行，加的绿、删的红，长了点「下一页」。也能按轮看：在明细里点一轮的「在侧边栏看 ›」，或者在侧边栏里点「按轮看 ›」（从最近改过文件的那一轮看起），就只列那一轮改的文件、比那一轮开始和结束时的快照，只改了一个文件的直接点开；上面点「‹ 上一轮」「下一轮 ›」翻（只翻改过文件的轮次），点「看整个会话」回去。用侧边栏右上角自带的 `×` 关掉；关掉后 HUD 第一行最右边出现「◂ 改动」，点了拉出来，窄终端也能开（不到 110 列时摆在输入框上方，不在右边）。关掉后屏幕右上角没有插件能画东西的地方，所以「◂ 改动」只能放在 HUD 上。你亲手关掉后，下次启动不再自己打开；点「◂ 改动」、或者在明细里点「在侧边栏看 ›」又打开，以后照常。
- **明细**：点 HUD 第一行最前面的 `▸`，在 HUD 下方展开（变成 `▾`），再点收起。窗口宽时分三列：轮次；工具耗时和上下文；每天花费和子 agent。窄时点标签切换。全靠鼠标点（这块在输入框下面，不能打字）：
  - 轮次：每轮的用时、花费、token（缓存过期的那一轮 `in` 是黄的）、上下文涨了多少（`ctx`，这一轮里自动压缩过的写「压缩」）、改的文件数和命令数，横条是这一列的大小。上面一行写现在的上下文、到多少自动压缩、还能撑几轮。点表头按那一列从大到小排（再点「轮」回到最近的在前）；多了翻页；点一行看那一轮改了哪些文件（点「在侧边栏看 ›」看具体改了哪几行）、哪些命令失败、缓存为什么没接上，太多时点「展开全部」；点一条失败的命令，原文放进输入框（已经打了字就另起一行接在后面）。跑满 5 轮多一条花费趋势。
  - 工具耗时：每种工具调用了几次、总共和平均、最长耗时、失败几次，点表头排序；点工具名列出它最慢的几次各跑的是什么命令、读写的什么文件、在第几轮。
  - 上下文：上下文里装了什么，对话、系统提示、内置工具说明、MCP 工具说明、记忆文件、技能列表各占多少，从大到小；下面写 MCP 按服务器分、各个记忆文件（CLAUDE.md 等）各占多少，按需才加载的工具说明另写一句（平时不占窗口）。数字是 Claude Code 照 `/context` 的算法在本地估的，不发请求；每轮跑完估一次，点「刷新」马上估。
  - 子 agent：类型、任务、状态、用时、调了几次工具、用了多少 token、在第几轮起的；点它看模型、交给它的任务和它交回来的报告。
  - 每天花费：用 [ccusage](https://github.com/ryoppippi/ccusage) 读本机所有会话的记录，算今天、近 7 天、近 30 天花了多少，最近 7 天每天一根横条；点「近 7 天按项目」看哪个项目花得多，当前项目标出来。额度要提前用完时也写在这里。ccusage 要读完所有记录，要几秒到十几秒，在后台降低优先级跑，15 分钟内不重复算（点「刷新」马上算），上一次的结果存着，下次启动先画上。没装 ccusage 时会提示 `npm i -g ccusage`。

## 安装（新机器）

1. 克隆到 mods 目录：

   ```sh
   git clone git@github.com:JunwenLu7777/Fee.git ~/.claude/mods/hud
   ```

2. 在 `~/.claude/settings.json` 的 `env` 里加上（已有其他目录就用 `:` 连接）：

   ```json
   {
     "env": {
       "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods/hud"
     }
   }
   ```

3. 重启 Claude Code。

更新：`git -C ~/.claude/mods/hud pull`。

## 开发

- `claude plugin validate .` 校验
- `claude plugin test .` 跑测试
- `.claude-plugin/types/` 由引擎加载 mod 时自动生成，已被忽略；加载过一次后可用 `tsc -p .` 做类型检查
